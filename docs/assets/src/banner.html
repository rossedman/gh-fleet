gh fleet

One change,
every repo,
tracked to merged.

A gh extension that opens the same PR across your org and follows it home.

pin-actions
$ gh fleet apply -f fleet.yaml --yes pr open acme/api https://github.com/acme/api/pull/1 created pr open acme/web https://github.com/acme/web/pull/1 created noop acme/worker 4 pr open · 1 noop · 1 skipped $ gh fleet apply -f fleet.yaml --yes pr open acme/api https://github.com/acme/api/pull/1 unchanged pr open acme/web https://github.com/acme/web/pull/1 unchanged 4 pr open · 1 noop · 1 skipped
