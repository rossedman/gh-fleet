gh fleet apply  /  every target repo, in parallel
01

Campaign

fleet.yaml: targets, a script, a PR template. The name derives the branch fleet/<name>.

02

Resolve

List the org once (cached 10 min), apply filters, find existing PRs in batches of 50.

03

Clone

Shallow clone of the base branch. An existing campaign branch is rebased onto it.

04

Run

Your script at the repo root, with FLEET_REPO and friends, under a timeout.

05

Decide

Exit code and git status pick one of four outcomes.

Each repo ends in one of these
noop

Nothing to change

Exit 0 and no diff. Nothing is pushed.

failed

Error kept, others go on

Non-zero exit or timeout. retry runs only these.

pr open

Commit, push, PR

Push fleet/<name>, then open or update the PR. 1 write per second.

merged

Done for good

Later runs skip the repo.

gh fleet status

GitHub is the source of truth

Reads every PR back by branch and by the hidden <!-- gh-fleet:campaign=<name> --> marker, so it works even with no local state.
